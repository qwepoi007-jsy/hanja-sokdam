# 속담 한마디 한자 놀이터 — 미션 기록판 (Firebase)

학생은 **반 코드 · 학번 · 이름**으로 입장해 미션 5개를 순서대로 해결하고, 교사는 **teacher.html**에서 학생별 진행 상황과 문항별 오답률을 실시간으로 확인합니다.

| 파일 | 역할 |
|---|---|
| `index.html` | 학생용 (기존 놀이터 + 로그인 · 미션 · 기록) |
| `teacher.html` | 교사용 실시간 대시보드 |
| `firebase-config.js` | Firebase 설정값 + 교사 이메일 (두 페이지 공용) |
| `database.rules.json` | Realtime Database 보안 규칙 |

> `firebase-config.js`를 채우기 전에는 학생 화면이 **연습 모드**(기록이 그 기기에만 저장)로 동작하므로 바로 열어 볼 수 있습니다.

---

## 1. Firebase 준비 (처음 한 번, 약 10분)

1. **프로젝트 만들기** — https://console.firebase.google.com → 프로젝트 추가 → 이름 입력(예: `hanja-sokdam`). Google 애널리틱스는 꺼도 됩니다. 요금제는 무료(Spark) 그대로 두세요.
2. **웹 앱 등록** — 프로젝트 개요의 `</>`(웹) 아이콘 → 앱 이름 입력 → 등록. 화면에 나오는 `firebaseConfig = { ... }` 안의 값을 `firebase-config.js`에 그대로 붙여 넣습니다.
3. **Realtime Database 만들기** — 왼쪽 메뉴 *빌드 → Realtime Database → 데이터베이스 만들기*
   - 위치: **싱가포르(asia-southeast1)** 권장
   - 보안 규칙: **잠금 모드**로 시작
   - 만든 뒤 화면 위쪽의 주소(`https://….firebasedatabase.app`)가 `firebase-config.js`의 `databaseURL`과 같은지 확인하세요. 비어 있으면 직접 넣습니다.
4. **보안 규칙 붙여 넣기** — Realtime Database → *규칙* 탭 → `database.rules.json` 내용 전체를 붙여 넣고 교사 계정(qwepoi007@gmail.com, bortaguni@gmail.com, bortaguni@naver.com)이 들어간 규칙을 *게시* (완료됨). 교사를 추가하려면 규칙의 이메일 목록과 `firebase-config.js`의 `TEACHER_EMAILS`를 함께 고칩니다.
5. **로그인 방식 켜기** — *빌드 → Authentication → 시작하기 → 로그인 방법*
   - **익명**: 사용 설정 (학생용 — 학생은 계정이 필요 없습니다)
   - **Google**: 사용 설정 (교사용)
6. **교사 이메일 등록** — `firebase-config.js` 맨 아래 `TEACHER_EMAILS` 목록도 같은 주소로 맞춥니다.
7. **승인된 도메인 추가** — Authentication → *설정 → 승인된 도메인* → `qksrhrrltnf-ctrl.github.io` 추가 (GitHub Pages 주소의 도메인 부분).

## 2. GitHub Pages에 올리기

1. 새 저장소(예: `hanja-sokdam`)를 만들고 파일 4개를 올립니다.
2. *Settings → Pages → Branch: main / (root)* → Save.
3. 1~2분 뒤 주소가 생깁니다.
   - 학생: `https://qksrhrrltnf-ctrl.github.io/hanja-sokdam/?class=2-3`
   - 교사: `https://qksrhrrltnf-ctrl.github.io/hanja-sokdam/teacher.html`

## 3. 수업에서 쓰기

1. 교사 화면에 Google 계정으로 로그인 → 반 코드 입력 → **학생 접속 주소**를 복사해 칠판/패들렛/QR로 안내합니다. (`?class=` 뒤의 반 코드가 자동 입력됩니다.)
2. 학생은 학번(숫자 4~6자리)과 이름을 넣고 입장합니다. 같은 기기에서는 다음 접속 때 자동 입장되고, 다른 기기에서도 같은 학번·이름이면 이어서 할 수 있습니다.
3. 미션은 ①→⑤ 순서로 열립니다. 수업 상황에 따라 교사 화면의 **모든 미션 잠금 해제**로 한꺼번에 열 수 있습니다.

### 미션과 기록 기준

| 미션 | 내용 | 통과 | 기록 |
|---|---|---|---|
| ① 신습한자 뜻·음 | 뜻·음 퀴즈 10문항(섞어서) | 8개 이상 | 맞힌 수/10 (끝에 다시 나오는 문제는 점수 제외) |
| ② 짝 맞추기 | 6쌍 | 완성 | 뒤집기 시도 횟수 (최소 6회) |
| ③ 속담 조립 | 본문 속담 4개, 단계별 | 4개 완성 | 실수 횟수 |
| ④ 이럴 땐 이 속담! | 상황 11문항 | 8개 이상 | 맞힌 수/11 |
| ⑤ 談虎虎至 탈출 | 종합 | 탈출 | 맞힌 수/푼 수 |

- **처음 기록**: 그 미션에 처음 도전했을 때 결과 — "얼마나 틀리지 않고 맞혔는지"를 보는 기본 지표입니다.
- **최고 기록 · 도전 횟수**: 다시 도전한 결과도 함께 남습니다.
- **처음 정답률**(학생별): 학생이 푼 모든 문항 중 **처음 풀었을 때 맞힌 문항**의 비율.
- **문항 분석**: 처음에 틀린 학생 비율이 높은 문항 순. 막대에 마우스를 올리면 틀린 학생 명단이 보입니다.
- 홈 화면 아래 **자유 연습** 활동(산성비, 시뮬레이터, 획순 등)은 기록되지 않습니다.

### 자주 생기는 일

- **"이미 다른 이름으로 등록된 학번"** — 학번을 잘못 입력한 학생이 먼저 등록한 경우입니다. 교사 화면에서 해당 학번 행을 눌러 **이 학생 기록 초기화** 후 다시 입장시키세요.
- **학생 화면 위에 "연습 모드" 경고** — Firebase 연결 실패입니다. 익명 로그인 사용 설정, 승인된 도메인, `databaseURL`을 확인하세요.
- **교사 화면 "읽기 권한 오류"** — 규칙의 이메일과 로그인한 계정이 다른 경우입니다.
- **CSV 내려받기** — 엑셀에서 바로 열립니다(한글 깨짐 방지 처리). 반·학번·이름, 미션별 통과/처음/최고/도전 횟수, 처음 정답률, 처음 틀린 문항 목록이 들어갑니다.

## 4. 용량과 개인정보

- 무료(Spark) 요금제의 동시 접속 한도는 **100**입니다. 학생 40명 + 교사 화면이면 여유가 있지만, 학생 한 명이 탭을 여러 개 열면 각각 1개로 셉니다. 여러 반이 **같은 시간에** 쓰면 합산되니 주의하세요.
- 답 하나에 아주 작은 기록(수십 바이트) 하나만 저장하므로 저장 용량·전송량 한도(무료 1GB/10GB)는 걱정하지 않아도 됩니다.
- 저장되는 정보는 반 코드, 학번, 이름, 미션 결과뿐입니다. 단원이 끝나면 교사 화면의 **이 반 기록 삭제**로 지워 주세요.
- `firebase-config.js`의 apiKey는 공개되어도 되는 값입니다. 실제 보호는 보안 규칙이 담당합니다: 학생 기록 전체를 읽고 지울 수 있는 것은 교사 계정뿐입니다. 다만 학생 입장은 비밀번호가 없으므로, 다른 학생의 학번을 알고 입력하면 그 학생 이름으로 기록을 이어 쓸 수는 있습니다(이름이 다르면 막힘).
